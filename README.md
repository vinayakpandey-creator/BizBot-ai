# BizBot AI

A beginner-friendly demo business website with:
- AI-style chatbot demo
- Customer enquiry form
- LocalStorage lead saving
- Admin dashboard
- Responsive design

## Run
Open `index.html` directly in a browser, or open the folder in VS Code and use Live Server.

Note: This is a front-end demo. The chatbot is rule-based and data is stored only in the browser. A real AI/backend can be connected later.
